# EcoTrack – Smart Waste Management System

A Semester 3 Python project using Tkinter and SQLite.

## Features in this starter version
1. Login screen
2. Dashboard with waste summary
3. Add waste records
4. View and delete waste records
5. Reports with category-wise totals
6. Export records to CSV

## Requirements
- Python 3.10 or newer recommended
- Tkinter (usually included with Python)
- SQLite (included with Python)

No third-party Python packages are required for this starter version.

## Run
Open a terminal in this folder and run:

```bash
python main.py
```

On some systems, use `python3 main.py`.

The file `ecotrack.db` is created automatically in the project folder on first launch.

## Notes
- Quantities are stored in kilograms.
- The starter version uses a simple category-to-recyclability mapping for demonstration.
- Actual recycling rules vary by local waste collection facility; confirm local rules before real-world use.
